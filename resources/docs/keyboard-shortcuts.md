# Keyboard shortcuts

Shortcuts are shown for the platform you are using.

## Application

| Action           | Shortcut                             |
| ---------------- | ------------------------------------ |
| Open location    | `Mod+Shift+O`                        |
| Refresh          | `Mod+R`                              |
| Focus the filter | `Mod+F`                              |
| Open help        | ⌘? on macOS, F1 on Windows and Linux |

## File lists

| Action                      | Key                       |
| --------------------------- | ------------------------- |
| Move between rows           | Up and Down arrows        |
| Open the selected item      | Enter                     |
| Open the row's actions menu | Shift+F10 or the Menu key |

## Help window

| Action                | Shortcut |
| --------------------- | -------- |
| Filter the topic list | `Mod+F`  |
