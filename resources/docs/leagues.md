# Leagues

A league lives under one league night and holds its seasons. The sidebar lists every league grouped by day. Days collapse and the app remembers which ones you collapsed per location.

## Creating a league

**New league…** on Home asks for the league night and a name. The app creates the league folder under that day and writes its `meta.json`. Folders you create by hand under a day folder are adopted on the next scan, so you can also make them in OneDrive directly.

## The league view

A league opens as a file browser: seasons at the top, newest first with their status, then any other files and the Archive folder. The overview adds season status badges, item counts and a filter for the current folder.

The league, archive and season panes share a desktop style file browser. Click to select and double click to open, with breadcrumbs leading back. In file lists, press Enter to open the selected item and use the arrow keys to move between rows.

Right click a row to open the same actions shown in its `…` menu: browse folders, open documents in their default app, or reveal items in Finder or Explorer.

## Renaming a league

**Rename league…** in the league's actions changes its display name. When the sanitised folder name changes as well, the app moves the league folder and its archives to match.

## Importing documents

Drop files into a league root, into Shared documents, into Templates or into a live season view to copy them in. Imports only ever add copies and never replace a file that is already there.

## Deleting a league

Deleting a league asks you to type its name, then moves the whole folder, including unmanaged files, to the OS trash. Nothing is deleted permanently by the app.
