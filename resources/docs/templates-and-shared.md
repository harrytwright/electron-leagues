# Templates and shared documents

Home shows two folders that belong to every league rather than to one of them.

## Templates

`_templates` holds the documents copied into every new season. A new location seeds it with the bundled `Rules.docx` and `Sign-In Sheet.docx`. Add your own by dropping files into the **Templates** tab or by saving them into the folder in OneDrive.

Only visible, direct files count as templates. Subfolders inside `_templates` are browsable but are never copied.

Edited defaults and custom templates are left alone by **Repair location…**, which only reseeds a bundled template whose filename is missing.

See [Seasons](seasons.md#creating-a-season) for how the starting documents options use templates.

## Shared documents

`_shared` holds general documents for every league, such as centre rules or contact sheets. The **Shared documents** tab on Home browses it. The app copies nothing out of it and treats it as a plain folder you organise yourself.

## Importing

Drop files into the Templates or Shared documents tabs to copy them in. Imports only ever add copies. A file with the same name is never replaced.
